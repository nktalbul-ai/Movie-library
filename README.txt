##Информация об авторе

##Описание программы

**Movie Library- это GUI-приложение для управления личной коллекцией фильмов.
Позволяет добавлять фильмы, фильтровать их по жанру и году,
сохранять и загружать данные в формате JSON,а также просматривать список с удобной навигацией.

### Возможности:
-✅ Добавить фильм: Вводишь название и данные — фильм сохраняется.
-✅ Фильтрация: Можно найти фильмы только одного жанра (например «Комедия») или только за определённый год (например «2023»).
-✅ Сохранение: Список фильмов не пропадёт после закрытия программы. Он сохраняется в специальный файл movies.json.
-✅ Проверка ошибок: Программа не даст сохранить фильм без названия или если рейтинг больше 10.

## Требования:
-Python 3.6 или выше
-Стандартная библиотека Tkinter
